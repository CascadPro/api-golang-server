# AGENTS.md — инструкции для AI-агентов

Кратко и по делу: эта заметка помогает AI-агентам быстро понять репозиторий и выполнять типичные задачи.

**Где смотреть**

- **Проект:** [README.md](README.md)
- **Основная точка входа:** [cmd/main.go](cmd/main.go)
- **Миграции:** [migrations](migrations)

**Ключевые команды (Makefile targets)**

- **Поднять окружение:** `make env-up` — запускает Postgres и Redis через Docker Compose.
- **Остановить окружение:** `make env-down`.
- **Применить миграции:** `make migrate-up` (локально через контейнер миграций).
- **Запустить приложение локально:** `make app-run` (зависит от `go mod tidy`).
- **Сгенерировать Swagger:** `make swagger-gen`.

Используйте эти цели вместо запуска сырых `docker`/`go` команд, если не указано иное.

**Ключевые директории и назначения**

- `internal/core` — конфигурация, логгер, доменные сущности и репозитории.
- `internal/features` — бизнес-фичи (например, `auth`, `sessions`).
- `internal/transport/http` — HTTP-сервер, роутинг и middleware.
- `migrations` — SQL миграции базы данных.

Советы для агентов

- Следуйте принципу «link, don't embed»: ссылайтесь на существующие документы (`README.md`, `migrations`, `docs/`).
- Не копируйте большие части документации в инструкции — добавляйте лишь короткие аннотации и ссылки.
- Для изменения окружения предпочтительнее использовать `Makefile` цели и `docker compose` сервисы, перечисленные в `Makefile`.

Если нужно, могу расширить этот файл: добавить шаблоны PR-комментариев, чек-листы для миграций или автоматические тесты.
